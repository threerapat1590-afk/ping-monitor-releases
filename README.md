# Ping Monitor — ไฟล์ติดตั้ง

ที่นี่มีแค่ไฟล์ติดตั้งของแอป Ping Monitor สำหรับ Mac กับสรุปการเปลี่ยนแปลงของแต่ละเวอร์ชัน (ไม่มีโค้ด)

**ดาวน์โหลด:** ไปที่ [Releases](../../releases/latest) แล้วโหลดไฟล์ `PingMonitor-<เวอร์ชัน>-arm64.dmg`

## ติดตั้ง
1. ปิด Ping Monitor ตัวเก่าก่อน (ถ้ามี)
2. เปิดไฟล์ `.dmg` แล้วลาก **Ping Monitor** ไปที่ **Applications**
3. ครั้งแรกที่เปิด macOS จะบล็อกแอป เพราะแอปยังไม่ได้เซ็นกับ Apple:
   - เปิด **System Settings → Privacy & Security**
   - เลื่อนลงไปที่ "Ping Monitor was blocked" แล้วกด **Open Anyway**
   - ทำครั้งเดียวต่อเวอร์ชัน
   - ถ้าขึ้นว่า "แอปเสีย" (damaged) ให้เปิด Terminal แล้วพิมพ์ `xattr -cr "/Applications/Ping Monitor.app"` จากนั้นเปิดใหม่

## ใช้กับ
- Mac ชิป Apple (M1 ขึ้นไป)
- แอปจะเช็ก Release ล่าสุดของที่นี่ตอนเปิด และขึ้นแถบแจ้งเมื่อมีเวอร์ชันใหม่ (ส่งแค่การขอข้อมูล Release ไม่ส่งข้อมูลของเรา)

## ความปลอดภัย
- แอปไม่เคยส่งคำสั่งแก้ config ให้ switch เอง
- รหัสผ่านที่บันทึกไว้เก็บใน Keychain ของ Mac เครื่องนั้นเท่านั้น
- ไฟล์ใน Release มีค่า SHA-256 ให้ตรวจว่าไฟล์ไม่ถูกแก้ระหว่างทาง
